## Оставшийся дефект Q2

На каждое воспроизведение создавалась новая копия `data/`. В `meeting_notes/leadership_sync_2026-06-17.md` добавлен протокол с датой 17 июня и разделом `Staffing decisions`. Команда одинакова.

```text
python ask/ask.py --q q2 --data <копия>
```

### Контроль, два предложения

```text
- **DECISION:** Engineering hiring freeze is lifted. Sales hiring remains frozen.
```

Код 0, Sales остаётся frozen. Первоначальный пример второго раунда исправлен.

### Одно сложное предложение

```text
- **DECISION:** Engineering hiring freeze is lifted, but Sales hiring remains frozen.
```

Код 0, фактический ответ следующий.

```text
**2. Current state: the Sales freeze is lifted**
- **Current state as of 2026-06-18: MEDIUM** (core checks failed: 0 of 5; flag checks failed: 3 of 7)
```

Тот же неверный результат получен при следующем тексте.

```text
- **DECISION:** Engineering hiring freeze is lifted; Sales hiring remains frozen.
```

Это прежняя ошибка смешения команд в другом обычном синтаксисе. Новый код разделяет записи только по границам предложений. Внутри одного предложения наличие Sales связывает с ним обе части, после чего приоритет LIFTED побеждает FROZEN. [Разделение предложений](<C:/Users/tonyu/OneDrive/Documents/ChatGPT/Analyst/Northwind-review-round3-2026-11-11/valis-case/ask/ask.py:57>) · [Привязка команд](<C:/Users/tonyu/OneDrive/Documents/ChatGPT/Analyst/Northwind-review-round3-2026-11-11/valis-case/ask/ask.py:505>)

**Предлагаемая правка.** Привязывать состояние к команде в соответствующей части сложного предложения. Для конструкции с несколькими командами, которую правила не умеют однозначно разобрать, выдавать NOT CERTAIN и LOW. Добавить оба воспроизведения в регрессионные проверки. Код решения в этом аудите не изменялся.
